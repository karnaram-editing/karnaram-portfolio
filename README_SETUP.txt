KARNARAM — GOOGLE DRIVE PORTFOLIO

HOW IT WORKS
1. You upload videos into your Google Drive portfolio folder.
2. Google Apps Script reads the KARNARAM PORTFOLIO folder and its subfolders.
3. The website loads the current video list when the page opens.
4. You do not need to edit the website for normal new uploads.

IMPORTANT
- The website uses your Apps Script Web App URL in script.js.
- Visitors do not get an upload button or access to the Apps Script editor.
- Your Apps Script code only reads files; it does not delete, move, rename, or upload files.
- Google Drive video previews may show Google's video player. Very large videos can take longer to load.
